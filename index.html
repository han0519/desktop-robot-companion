常用地址：bootloader 0x0、分区表 0x8000、ota_data 0xf000、 应用固件一般为 0x10000 或 0x120000（以你工程的构建输出为准）。 各文件地址区间不能重叠。文件只在你的浏览器本地读取，不会上传到任何服务器。
⚠️ 当前浏览器不支持网页烧录。请改用 Google Chrome 或 Microsoft Edge （版本 89 以上），并且要通过 https:// 网址访问本页面。手机浏览器暂不支持。

📋烧录步骤

  • 数据线连接板子与电脑（注意：有些线只能充电不能传数据，请用能传数据的线）
  • 点击上方 「连接并烧录」按钮，浏览器弹出串口选择框
  • 选择板子对应的串口（Windows 上一般是 COMx；如果列表为空，检查线缆或换个 USB 口）
  • 等待烧录进度走完，看到 成功 提示后拔线即可

🚀烧录完之后

  • 板子开机后会开一个名为 Robot-Config 的热点，手机连上它，随便打开一个网页就会弹出配网页面，填入家里 WiFi 即可
  • 配好网后，如果板子还没在 xiaozhi.me 激活，表情屏会显示设备码，去 xiaozhi.me 输入设备码完成绑定
  • 之后喊「你好小智」就能对话；网易云音乐在网页控制台「音乐」页扫码登录（默认直连，无需服务器）

❓常见问题

「自定义固件」模式怎么用？
切到「🔧 自定义固件」→ 选择板子芯片（如 ESP32-S3）→ 点「添加文件」选择 .bin 文件并填写烧录地址（如 bootloader 填 0x0）→ 点「连接并烧录」。可以添加多个文件分别写到不同地址，适合刷其他 ESP32 项目（如 ESPHome、Tasmota、自己的 Arduino/IDF 工程等）。
自定义模式支持哪些芯片？文件会上传吗？
支持 ESP32 / ESP32-S2 / ESP32-S3 / ESP32-C2 / C3 / C5 / C6 / C61 / ESP32-H2 / ESP32-P4 / ESP8266。ESP32-S31 太新，当前网页烧录库还不支持，需要用 esptool 命令行烧录。所有文件只在浏览器本地内存中读取，不会上传到任何服务器。
点按钮后弹窗里看不到串口 / 烧录失败怎么办？
依次尝试：① 换一根确定能传数据的 USB 线；② 换个 USB 口（尽量直插主板，不用 hub）；③ 安装 CH340/CP2102 驱动（部分国产板子需要）；④ 如果卡在「连接中」，按住板子上的 BOOT 键不放、点一下 RESET 键，让板子强制进入下载模式。
烧录会清掉板子里原来的东西吗？
弹窗里会有「擦除设备」选项，建议勾选，原来的 WiFi 配置、登录信息都会被清掉，烧录后需要重新配网 —— 这正是新板子开箱应有的状态。
为什么必须用 Chrome / Edge？
网页烧录依赖浏览器提供的 Web Serial 串口能力，目前只有 Chrome / Edge（89+）支持，Firefox 和 Safari 暂不支持。另外页面必须是 https 访问（GitHub Pages 自动满足）。
