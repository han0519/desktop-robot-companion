# 测试脚本使用说明

tests/ 目录下存放各组件的独立测试代码。

## 使用方法

1. 将 `tests/test_all.c` 复制为 `main/main.c`（覆盖原文件）
2. 编译烧录：`idf.py build flash`
3. 观察 OLED 和串口输出，依次验证各组件
4. 测试完成后恢复原 `main.c`

## 测试项

| 顺序 | 测试项 | 验证方法 |
|------|--------|----------|
| 1 | OLED | 屏幕显示 "OLED TEST OK" |
| 2 | 舵机x3 | 三个舵机依次 0°→180° 转动 |
| 3 | WS2812 | 灯环和板载灯依次 红→绿→蓝 |
| 4 | 传感器 | 屏幕实时显示 IR/TOUCH 状态和温湿度 |
| 5 | 完成 | 显示 "ALL TESTS DONE" |

## 单独测试

如需单独测试某个组件，可在 main.c 中注释掉其他测试段，只保留需要的部分。

## 常见问题

- **舵机不动**: 检查 5V 供电和共地，信号线是否接对 GPIO
- **WS2812不亮**: 检查灯环供电(5V)和数据线(GPIO39)，板载灯需短接RGB跳线
- **DHT11读不到**: 检查接线，读取间隔需≥2秒
- **I2C超时**: 检查 SDA/SCL 是否接反，降低时钟到100kHz
