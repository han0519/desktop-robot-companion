⑦ 注意事项
1. 共地：所有 GND 都接电源模块 GND（含 ESP32 开发板）
2. 插拔舵机/模块 先断电
3. WS2812 是 5V 器件，不要接 3.3V；珠子多或首珠不亮就在 DATA 加电平转换（74HCT245）
4. 接线顺序建议：电源 → ESP32 → OLED → 舵机 → 触摸/红外/DHT11 → 音频 → 灯环
5. 3 个舵机同转峰值约 1.5A，电源模块 5V/3A 够用
6. 电池供电时不插开发板 Type-C，烧录时才插
