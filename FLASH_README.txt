桌面摆件机器人 一键烧录包 v1.1.0
================================

【这是什么东西？】
- robot_companion_merged.bin 是【整个固件】的合并镜像，已经把
  bootloader（引导） + 分区表 + OTA 数据 + 唤醒词模型 + 主程序
  打包成【一个文件】。
- flash.bat 是【一键烧录脚本】，双击即可，不用懂命令行。

【怎么用？】三步搞定
1. 电脑装 Python 3：https://www.python.org/downloads/
   安装时勾选 "Add python.exe to PATH"。
2. 用【数据线】（不是充电线）把机器人连电脑。
3. 解压本包，双击 flash.bat，等它自动跑完看到 [成功] 就行。

【常见问题】
- 提示找不到设备：按住开发板上的 BOOT 键再插 USB 试试。
- 烧录失败：先关掉别的串口软件（如 Ardunio 串口监视器），重试。
- 本烧录不会清空 WiFi 配置和网易云登录状态（NVS 保留）。
