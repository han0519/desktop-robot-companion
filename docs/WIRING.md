# 接线说明

> 配件清单：ESP32-S3-N16R8 开发板 + SSD1305 OLED(128x64, I2C) + INMP441 麦克风
> + MAX98357A 功放 + 喇叭 + WS2812 灯环(8珠) + 2x FC-51 红外避障 + 2x TTP223 触摸
> + 2x SG90 舵机(180°) + DHT11 温湿度 + 充电模块 + 降压电源模块(6-30V→5V/3.3V)
> + 自锁开关 + 2 串锂电池(7.4V)

## 一、电源链路（先接这个）

**一句话：电池 7.4V → 充电板 B+/B- → 开关 → 电源模块输入 → 5V/3.3V 分给各配件。**

```
2串锂电池(7.4V)
   ├─ 电池正极 ──→ 充电模块 B+
   └─ 电池负极 ──→ 充电模块 B-
                     │
充电模块 B+ ──→ 开关 脚1
开关  脚2  ──→ 电源模块 输入端子 +
充电模块 B- ──→ 电源模块 输入端子 -
                     │
        ┌────────────┼────────────┐
      5V(3A)       3.3V(3A)       GND
   (绿色排针)    (黄色排针)     (黑色排针)
```

| # | 连接 | 说明 |
|---|---|---|
| 1 | 电池正极 → 充电模块 `B+` | |
| 2 | 电池负极 → 充电模块 `B-` | |
| 3 | 充电模块 `B+` → 开关 脚1 | 正极过开关，关断即整机断电 |
| 4 | 开关 脚2 → 电源模块 输入 `+` | |
| 5 | 充电模块 `B-` → 电源模块 输入 `-` | 负极直连，不过开关 |
| 6 | Type-C → 充电模块 USB 口 | **仅充电时插**，充满拔掉 |

- 开关用**自锁式**，串在电池正极和电源模块输入之间
- 充电时建议把整机开关关掉
- 2 串锂电标称 7.4V，充满 8.4V；电源模块输入 6-30V 完全覆盖

### 5V 分配（电源模块绿色排针）

| 设备 | 接线 |
|------|------|
| ESP32-S3 开发板 | `5V` 脚 → 5V |
| 舵机1（左右转） | 红线 → 5V |
| 舵机2（上下点） | 红线 → 5V |
| MAX98357A 功放 | `VIN` → 5V |
| WS2812 灯环 | `VCC` → 5V（**灯环是 5V 器件，别接 3.3V**） |

### 3.3V 分配（电源模块黄色排针）

| 设备 | 接线 |
|------|------|
| OLED 屏幕 | `VCC` → 3.3V |
| INMP441 麦克风 | `VDD` → 3.3V |
| TTP223 触摸 ×2 | `VCC` → 3.3V |
| DHT11 | `VCC` → 3.3V |
| 红外避障 ×2 | `VCC` → 3.3V |

### GND

> 所有设备的 GND 全部接到电源模块的 GND（包括 ESP32 开发板），**必须共地**。

## 四、注意事项

1. **共地**：所有设备 GND 接电源模块 GND，ESP32 的 GND 也接那里
2. 换舵机/插拔线**先断电**
3. WS2812 是 **5V** 器件，不要接 3.3V
4. 接线顺序建议：电源 → ESP32 → OLED → 舵机 → 触摸/红外/DHT11 → 音频 → 灯环
5. 3 个舵机同时转峰值约 1.5A，电源模块 5V 输出 3A 够用
6. WS2812 全白很耗电，固件里做了单帧电流预算限流（见 `main/light.c`）
